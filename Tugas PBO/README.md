B. PETUNJUK DAN TATA TERTIB 
1. Pilih dan kerjakan minimal dua (2) kasus yang berbeda dari lima kasus yang 
disediakan. 
2. Seluruh penyelesaian harus menggunakan Python 3 dan konsep Pemrograman 
Berorientasi Objek (PBO), bukan sekadar kumpulan instruksi prosedural. 
3. Setiap kasus wajib menggunakan class, objek, atribut, konstruktor __init__(), 
dan minimal dua method yang relevan. Terapkan enkapsulasi sederhana melalui 
method untuk mengelola atau memvalidasi data. Penggunaan pewarisan 
(inheritance) bersifat opsional apabila sesuai dengan kebutuhan kasus. 
4. Program wajib menerima masukan dari pengguna melalui terminal, melakukan 
validasi input, dan menampilkan keluaran sesuai ilustrasi. Format tampilan boleh 
berbeda, tetapi perhitungan dan informasi wajib benar. 
5. Sebelum mulai menulis kode, aktifkan screen recording satu layar penuh (full 
screen desktop) dan stopwatch. Rekaman wajib menunjukkan seluruh layar kerja 
(bukan hanya jendela VS Code), stopwatch yang berjalan kontinu, pengetikan kode 
secara langsung, dan eksekusi program di terminal. 
6. Catat waktu mulai ketika pengerjaan dimulai. Setelah seluruh kasus pilihan selesai, 
catat waktu selesai dan durasi total stopwatch. Jangan menghentikan stopwatch 
ketika berpindah dari kasus pertama ke kasus kedua. 
7. Ketentuan Ketat Tanpa AI (Strict No-AI Policy): 
o Dilarang keras menggunakan alat bantu kecerdasan buatan (AI), seperti 
LLM/Chatbot (ChatGPT, Claude, Gemini, DeepSeek, dsb.). 
o Dilarang menggunakan ekstensi/fitur AI autocompletion pada VS Code 
(seperti GitHub Copilot, Codeium, Tabnine, Cursor, dsb.). Semua ekstensi AI 
wajib dalam kondisi dinonaktifkan (disabled) sepanjang rekaman. 
o Dilarang menyalin (copy-paste) kode dari repositori luar, AI, maupun 
peserta lain. Seluruh kode harus murni diketik langsung oleh peserta. 
o Segala bentuk manipulasi rekaman, jeda waktu mencurigakan, atau indikasi 
pemakaian AI mengakibatkan diskualifikasi dengan nilai otomatis 0 (E). 
8. Setelah selesai, unggah kode ke satu repository GitHub dan kumpulkan tautan 
repository, rekaman layar, serta laporan waktu sesuai Bagian E. 
9. Pengerjaan kurang dari dua kasus dinyatakan tidak memenuhi persyaratan 
minimum ujian.
